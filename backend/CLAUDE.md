## Claude Code 전용

- 작업을 끝내기 전에 `./gradlew test`를 실행하고 결과를 보고한다. 실패하면 완료라고 하지 않는다.
- 커밋·push·PR은 사용자가 승인한 뒤에만 한다.
- 커밋 메시지·scope는 루트 `CONTRIBUTING.md`를 따른다. 백엔드는 `be`.
- 명세와 충돌하는 구현이 필요하면 코드를 먼저 쓰지 말고 멈추고 보고한다.
- 파일을 외부에서 바꾼 경우 IntelliJ가 이전 내용을 덮어쓸 수 있다. 작업 후 Reload All from Disk를 안내한다.
